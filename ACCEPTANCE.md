# ACCEPTANCE.md — фактически выполненные проверки (тестовый мини-проект)

Дата: 2026-10-26. Продукт-сайт (витрина «детейлинг премиум») поверх мини-PWA. Всё проверено в реальном
браузере на `npm run preview` (встроенный браузер OpenCode + headless Chrome puppeteer-core).

## Дизайн-система

- [x] Сгенерирована через ui-ux-pro-max `--design-system --variance 8 --motion 6 --density 7`
      (тема «dark mode automotive detailing studio»): тёмная палитра pure black + white, Archivo /
      Space Grotesk, style Motion-Driven.
      Источник истины: `design-system/sgx-detailing-site/MASTER.md`.
- [x] Токены MASTER.md перенесены в `src/index.css` (палитра, радиус 0, `--space-*` в :root,
      reveal-анимации с отключением при `prefers-reduced-motion`).
- [x] При приёмке найден и исправлен конфликт: собственные spacing-токены в `@theme`
      перебивали Tailwind-шкалу (`max-w-xs` → 4px, разваливал футер); исправлено переносом в `:root`
      под именами `--space-*` (проверено computed style: maxWidth 320px).
- [x] Первая генерация (Brutalism light+gold) была отклонена как не соответствующая ТЗ (требуются
      тёмные плотные интерфейсы) и перезаписана валидным запросом с `dark mode`.

## Состав сайта

- [x] Header: sticky, якорная навигация, CTA. На <=sm логотип сокращается до первого слова
      (композит из business.name — не захардкожен).
- [x] Hero: асимметрия (7/5 на desktop), заголовок из business.name, до/после фото-плейсхолдеры
      с явным маркером «демо-заглушки фото», контакты из business.json.

- [x] Отзывы: 3 демо-заглушки, каждая помечена badge «demo» + баннер «ДЕМО-КОНТЕНТ…НЕ РЕАЛЬНЫ».
- [x] Кабинет: журнал записей владельца (localStorage `<business.id>.bookings.v1`), отмена записи.
- [x] Footer: только данные из business.json + явный дисклеймер «Демо-сайт… реальные компании не

## Браузерный проход сценариев (реальные клики/ввод, a11y-снапшоты как фиксация факта)

- [x] 375px: горизонтального оверфлоу НЕТ — инструментальный замер (puppeteer): scrollWidth=375 и
      0 элементов за границей вьюпорта. Скрин: shot-375 (папка отчёта).
- [x] 1440px: hero 7/5, секции на месте (скрин shot-1440).
- [x] Lighthouse: Accessibility 0.97, Best Practices 1.0, SEO 0.8
      (снижения: crawlable anchors на якорях навигации `#services`/`#cabinet`/`#top` в адресе
      локального preview — см. отчёт Lighthouse. Не блокирующий факт).
- [x] Короткий путь записи: клик по услуги → диалог с предвыбранными датой и первым свободным
      слотом (проверено: Комплексная мойка открылась с пн, 26 окт и слотами 10:00/13:00/16:00).
- [x] Валидация телефона: «нет телефона» → ошибка «Укажите корректный телефон», запись НЕ создана.
- [x] Полный flow: +7 900 123-45-67 → Подтвердить → «ЗАПИСЬ СОЗДАНА» с датой/временем и
      ID CF8DBFAF; запись в localStorage ключ `graphite.bookings.v1` (провеено содержимое).
- [x] Валидация времени: смена даты сбрасывает слот → «Подтвердить» → ошибка «Выберите время».
- [x] Занятость слота: после записи на пн 10:00 повторное открытие dialogs → кнопка 10:00
      `disabled=true` (13:00/16:00 активны). Двойная запись в один слот невозможна (UI-факт;
      идемпотентность-гвард в confirm также сохранена из AGENTS №3).
- [x] Day-blocker: запись «Полировка кузова» (8 ч = запись F0B67F44 на вт 27 окт 10:00) → в
      диалоге «Комплексная мойка» на вт 27 окт ВСЕ слоты 10:00/13:00/16:00 disabled=true.
- [x] Выходные: список дат 5 рабочих дней (пн–пт), сб/вс отсутствуют (worksOnWeekend:false).
      Сценарий «выходной-в-середине-недели» не воспроизводим в текущей календарной позиции:
      ближайшие сб/вс выпадают за пределы окна дат; логика slotsFor не менялась (даёт пусто на
      выходные — инвариант AGENTS №5).
- [x] Отмена: кабинет → «Отменить» у записи F0B67F44 → запись исчезла из localStorage
      (осталась только CF8DBFAF).
- [x] Консоль: 0 сообщений уровня warning/error во время всего прохода.
