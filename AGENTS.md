# AGENTS.md — GRAPHITE тестовый проект (мини-PWA «онлайн-запись»)

Демонстрационный проект по методике SGX «24 часа вайбкодинга». Мини-таят-версия продукта:
PWA онлайн-записи детейлинг-студии, переодевается под другой бизнес через один файл.

## Инварианты (соблюдать строго)

1. `src/config/business.json` — единственный вход бизнес-конфига; названий бизнесов в `src/*.tsx` не должно быть (кроме business.json).
2. Слоты считаются из рабочих часов (`workingHours`) и длительности услуги; длинные услуги (>4 ч) блокируют весь день.
3. Повторный confirm с теми же датой/временем/телефоном не создаёт дубль (идемпотентность).
4. Ключ localStorage всегда `<business.id>.bookings.v1` — изоляция tenants.
5. Выходные не дают слотов (`worksOnWeekend: false`).
6. Никаких секретов в репозитории; внешние интеграции описаны в `.env.example`.

## Технологии

React 19 + TypeScript strict + Vite 8 + Tailwind CSS 4 + shadcn/ui (new-york) + lucide-react,
PWA через vite-plugin-pwa (generateSW). Дизайн-системы из скилла ui-ux-pro-max:
активная — `design-system/sgx-detailing-site/MASTER.md` (тёмный продукт-сайт, Archivo/Space Grotesk),
историческая (мини-PWA) — `design-system/graphite/MASTER.md` (сохранена, не используется).

## Порядок работы этапами

1. Конфиг и типы → 2. UI-компоненты (shadcn add) → 3. Бронирование → 4. Кабинет/отмена →
5. PWA-манифест/иконки → 6. build + браузерная приёмка (диалог → слот → телефон → confirm →
кабинет; повторный слот disabled; день занят длинной услугой).

## Проверки

- `npm run build` (tsc strict + vite) — обязательно зелёный.
- Браузерный проход сценариев (см. ACCEPTANCE.md) — не ограничиваться одним скриншотом.
